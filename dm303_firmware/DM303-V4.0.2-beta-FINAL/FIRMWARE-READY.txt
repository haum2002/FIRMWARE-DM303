================================================================================
CARA CEPAT MEMASANG (QUICK START):
================================================================================

1. FORMAT SD Card ke FAT32
2. SALIN fail .bin dan folder 'system' ke root SD Card
3. MASUKKAN SD Card ke DM303 (peranti MATI)
4. TEKAN & TAHAN butang UPDATE/OK
5. HIDUPKAN peranti sambil terus tahan butang
6. TUNGGU sehingga selesai (jangan lepas butang!)
7. REBOOT automatik - KELUARKAN SD Card

================================================================================
VERIFIKASI SELEPAS FLASHING:
================================================================================

1. Semak versi: Menu > About > Pastikan "V4.0.2b"
2. Uji bahasa: Menu > Settings > Language > Pilih Malay/English
3. Uji bacaan: Pasang beban, perhatikan kestabilan
4. Uji lampu: Tekan butang lampu (singkat) untuk tukar tahap
5. Uji navigasi: Tekan & tahan butang menu untuk scroll pantas

PENYELESAIAN MASALAH RINGKAS:
================================================================================

"Loading Failed":
→ Pastikan .bin dan folder 'system' ada di root SD Card
→ Format semula SD Card ke FAT32
→ Cuba SD Card berbeza (SanDisk/Kingston 4-16GB)

Bahasa Melayu tidak muncul:
→ Pastikan TEXT_MS.DAT ada dalam folder 'system'
→ Tukar bahasa manual: Menu > Settings > Language > Malay

Bacaan tidak stabil:
→ Bersihkan probe dengan alkohol isopropil
→ Periksa kabel probe tidak longgar
→ Firmware sudah ada filter EMI maksimum

Lampu tidak bertahap:
→ Tekan SEKALI sahaja (jangan tahan)
→ Urutan: OFF → 25% → 50% → 100% → OFF
