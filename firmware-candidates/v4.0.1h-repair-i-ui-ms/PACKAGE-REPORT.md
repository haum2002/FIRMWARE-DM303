## What Is Added Over Repair-I

- Spanish language-name slot is renamed in-place to `Melayu`.
- `TEXT_SP.DAT` is rebuilt from the official SP 773-entry layout.
- Available Malay translations now replace 137 entries with zero too-long
  skips.
- Dark nav/menu icon assets are generated by direct RGB565 pixel tinting.
- No encoder, resize, compression, BMP header rewrite, or bit-depth conversion
  is used.

## What Stays Vendor/Official

- Firmware updater/bootloader path.
- Font resources: `ASCII64.dat`, `ASCII96.dat`, `HZK-ALL.GBK`.
- Logo resources.
- Help/manual text resources except the SP language slot.
- All non-overlay official V4.0 system resources.
- Stream/IO, relay settle, UI render, and boot-logo timing windows.

## Important Limit

This is still not true add-only language activation. The hardcoded language
table has no confirmed spare slot, so the SP slot is reused. This is safer than
changing table size, but it means Spanish is sacrificed in this overlay.

If `V4.0.1o` still shows calit, do not test this overlay yet. If `V4.0.1o`
removes calit, this overlay is the next controlled UI test.
