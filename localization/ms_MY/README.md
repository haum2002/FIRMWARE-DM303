# DM303 Malay UI text resource

Status: sumber resource Bahasa Melayu untuk staging dan pakej akhir
`v4.0.1 beta`.

> Nota 2026-07-18: senarai destinasi salinan lama di bawah (bahagian "TEXT_MS.DAT
> is copied into") merujuk garis `V4.0.1h` yang telah GAGAL/dikuarantin — abaikan
> laluan tersebut. Pakej akhir semasa disenaraikan dalam `README.md` root.

Files in this folder are generated from
`backup/DM303 V4.0-read only/system/TEXT_EN.DAT` with
`tools/dm303_make_ms_pack.py`.

- `TEXT_MS.DAT` is the standalone Malay text resource.
- `TEXT_SP.ms-slot-replacement.DAT` is the Malay resource prepared for replacing
  the existing Spanish slot during controlled device testing.
- `TEXT_PO.ms-slot-candidate.DAT` is the same resource named as a possible
  Portuguese-slot replacement candidate for controlled testing later.
- `icon-SP.dat` is the Malay graphical label pack for the reused Spanish slot.
  It keeps the official 17-frame `92x24` BMP-pack size used by non-Chinese
  language packs.
- `translations_ms.csv` is the reviewable text source generated by the tool.

## Full-Malay SP-slot build chain (current, 2026-07-17/18)

This is the chain that produces the `TEXT_SP.DAT` shipped in the final
`V4.0.1p`/`V4.0.1r` packages (SHA-256
`f955f4c83a57ac26150536a377f29b40c5d64fc5ceb2991e2c5fb7ef6c147fd9`):

- `build_translations_ms_sp_full.py` — generates
  `translations_ms_sp_full.csv`: a Malay translation for every one of the 773
  official TEXT_SP entries, keyed by SP index. Enforces pure-ASCII output,
  exact per-entry byte length (`record_length - 2`), device placeholder
  tokens, and the official alignment/column layout. Run from repo root:
  `python localization/ms_MY/build_translations_ms_sp_full.py`.
- `translations_ms_sp_full.csv` — the reviewable translation table
  (`index,source,translation`); 757 entries translated, 16 kept verbatim
  (blank spacers / pure symbols / conventions).
- `validate_translations_ms_sp_full.py` — independent validator for the CSV:
  re-reads `analysis/sp_entries_source.csv` and checks row count/order, byte
  lengths, ASCII, verbatim source column, tokens, spacer/symbol rows, and the
  alignment rules. Exits non-zero on any violation.
- `TEXT_SP.full-slot-replacement.DAT` — the built binary resource, produced
  from the CSV with:
  `python tools/dm303_text_resource.py --input "backup/DM303 V4.0-read only/system/TEXT_SP.DAT" --rebuild localization/ms_MY/TEXT_SP.full-slot-replacement.DAT --translations-csv localization/ms_MY/translations_ms_sp_full.csv`
  It keeps the official 32888-byte size and a byte-identical offset table.
  This is the file staged into overlay candidates and verified by
  `tools/dm303_ui_overlay_candidate_check.py`.

## Superseded variant

- `TEXT_SP.safe-slot-replacement.DAT` (+ `.csv`) — earlier 137-entry safe
  build (2026-07-16, SHA-256 `96bde6bc...`). Field feedback showed index
  misalignment beyond entry 89 (TEXT_EN/TEXT_SP are not index-aligned), so it
  was replaced by the full build above. Kept for provenance only; do not ship.

The firmware binary does not add a new language slot. For the current safe test
path, select `Melayu`; this is the original Spanish slot renamed in place. That
slot now loads Malay text and Malay graphical menu labels.
