# DM303 Malay UI text candidate

Status: candidate resource only. This is not a flashable firmware update.

Files in this folder are generated from `DM303-V4.0/system/TEXT_EN.DAT` with
`tools/dm303_make_ms_pack.py`.

- `TEXT_MS.DAT` is a standalone Malay text resource candidate.
- `TEXT_PO.ms-slot-candidate.DAT` is the same resource named as a possible
  Portuguese-slot replacement candidate for controlled testing later.
- `translations_ms.csv` is the reviewable text source generated by the tool.

The current firmware binary does not reference `TEXT_MS.DAT`. To make Malay
appear in the device UI without firmware patching, a later controlled test may
need to use an existing language slot. Do not copy or rename this file into
`DM303-V4.0/system/` until resource loading and rollback steps are confirmed.
